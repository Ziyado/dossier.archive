# Licensed fonts

The site uses Gotham Book and Europa Light. These are commercial typefaces, so their files aren't included here. Until they're added, the site falls back to Montserrat (for Gotham) and Mulish (for Europa).

To use the real fonts, place web-font files you hold a **web licence** for in this folder, with these exact names:

- `Gotham-Book.woff2`
- `Europa-Light.woff2`

No code change is needed; the site picks them up automatically. Josephine Sans is loaded from Google Fonts as Josefin Sans.
